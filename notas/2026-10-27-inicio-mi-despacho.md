# Inicio de Mi Despacho

**Fecha:** 2026-10-27
**Etiquetas:** #personal #organizacion

---

## Resumen

Hoy creé **Mi Despacho**, mi repositorio personal en GitHub para guardar y organizar mis proyectos, notas y plantillas.

## Contenido

- Creé el repositorio en GitHub y lo conecté con Claude.
- Escribí el README con la descripción del repositorio.
- Organicé tres carpetas:
  - `proyectos/` para mis proyectos.
  - `notas/` para ideas y apuntes.
  - `plantillas/` para archivos base que reutilizo.
- Hice una plantilla de notas (`plantillas/nota.md`) y con ella escribí esta primera nota.

## Próximos pasos

- [ ] Decidir cuál será mi primer proyecto y crear su carpeta en `proyectos/`.
- [ ] Escribir una nota cada vez que tenga una idea que quiera guardar.
- [ ] Añadir más plantillas si las necesito (por ejemplo, para proyectos o reuniones).
